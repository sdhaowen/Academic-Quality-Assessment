# 信息科技（人工智能）核心素养学业质量评价可视化工具

用户使用手册（V1）

---

## 1. 产品简介

本工具是一个基于 Web 的学业质量评价可视化系统，用于展示学生在人工智能核心素养方面的达成情况与增值变化。

系统支持：

- 小学段与初中段两套指标体系
- 1-5 分评价量表
- 学生/班级/多班级/校际四类雷达图
- 手动录入评分
- Excel 导入评分数据
- 半年、一年、五年的长期增值分析

---

## 2. 使用前准备（必须安装的软件）

### 2.1 必需软件

1. **Node.js（建议 LTS 版本，18 或 20 及以上）**
   - 下载地址：https://nodejs.org/
   - 安装后会自动包含 `npm`

2. **现代浏览器（任选其一）**
   - Google Chrome（推荐）
   - Microsoft Edge
   - Firefox

### 2.2 可选软件（建议）

1. **Git**（用于获取/更新项目代码）
   - 下载地址：https://git-scm.com/

2. **代码编辑器（用于维护部署）**
   - VS Code / Cursor / WebStorm 均可

### 2.3 版本检查命令

安装后，可在终端执行：

```bash
node -v
npm -v
```

若能输出版本号，说明环境准备完成。

---

## 3. 安装与启动

以下步骤适用于 Windows / macOS / Linux。

### 3.1 获取项目代码

如果你已经有项目文件，直接进入项目目录即可；否则可执行：

```bash
git clone <你的仓库地址>
cd Academic-Quality-Assessment
```

### 3.2 安装依赖

```bash
npm install
```

### 3.3 启动开发服务

```bash
npm run dev
```

终端会显示本地访问地址（通常是 `http://localhost:5173`），在浏览器打开即可使用。

### 3.4 生产构建（可选）

```bash
npm run build
```

构建完成后会生成 `dist/` 目录，可用于静态部署。

## 4. 功能操作指南

## 4.1 首页布局说明

1. **顶部导航**
   - 学段切换：小学 / 初中
   - 时间跨度：半年 / 一年 / 五年

2. **左侧功能模块**
   - 学生个人看板

   - 多班级对比

   - 数据管理

3. **中间主区域**
   - 数据概览卡片（学生人数、记录数、最近评价时间等）
   - 四类雷达图
   - 增值分析结果
   - 数据录入区（手动录入 + Excel 导入）

---

## 4.2 四类雷达图怎么看

1. **学生增值性图表**
   - 展示同一学生在不同时间点的叠加雷达图
   - 用于观察成长轨迹

2. **班级雷达图**
   - 当前班级各指标平均分

3. **多班级对比图**
   - 2-3 个班级在同一坐标下比较

4. **校际对比图**
   - 多学校平均表现差异

> 鼠标悬停到图形区域可查看 Tooltip 的具体分值。

---

## 4.3 手动录入评分

1. 在“手动录入（1-5 星）”区域选择学生
2. 选择评价日期
3. 对 8 项指标逐项打分（1-5）
4. 点击“保存评价记录”

### 评分参考说明

- 1 分：尚未达成
- 3 分：水平一（合格）
- 5 分：水平三（优秀）

系统为每个星级提供提示说明（Tooltip），便于教师统一评分口径。

---

## 4.4 Excel 导入评分

### 支持文件格式

- `.xlsx`
- `.xls`

### 必需列名

- `姓名`
- `学号`
- `评价日期`

### 指标列要求

可使用以下任一方式：

1. `指标1` 到 `指标8`
2. 直接使用对应学段的中文指标名

### 数据规则

- 指标分值必须是 **1-5** 之间的数字
- 评价日期必须可被解析为有效日期
- 学号需存在于当前学段学生名单中

### 导入结果

- 成功：显示导入条数，并自动刷新图表与统计
- 失败：显示错误列表（行号 + 原因）

---

## 4.5 长期增值分析

通过顶部“时间跨度”选择半年/一年/五年后，系统自动计算：

1. 该跨度内“最早记录 vs 最近记录”的差值
2. **素养提升率**
3. **进步最快指标**
4. **需进一步提升指标**

并对当前结果中达到：

- **3 分**（合格）
- **5 分**（优秀）

的指标做等级标注，帮助教师快速识别学业质量层级。

## 6. 常见问题（FAQ）

### Q1：启动时报错 `node` 命令不存在？

A：说明 Node.js 未安装或环境变量未生效。请重新安装 Node.js LTS，并重启终端后重试。

### Q2：`npm install` 很慢或失败怎么办？

A：可检查网络连接；必要时切换 npm 源后重试，或在稳定网络环境下再次执行。

### Q3：Excel 导入提示“缺少必需列”？

A：请确认表头包含：`姓名`、`学号`、`评价日期`，且不要有错别字。

### Q4：为什么提示“学号不在当前学段名单中”？

A：当前页面学段与 Excel 数据学段不一致，或学号未录入系统。请切换正确学段或补充学生名单。

### Q5：图表没有变化？

A：请确认导入记录有效且分值合法；也可尝试刷新页面并重新导入。

## 7. 数据安全与隐私建议

本工具涉及学生学业数据，建议：

1. 仅在校内网络或本地环境部署
2. 不上传包含身份证号、手机号、家庭住址等敏感信息的文件
3. 定期备份数据并设置访问权限
4. 对外展示时尽量使用匿名化或汇总数据

---
