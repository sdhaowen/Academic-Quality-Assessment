# Academic-Quality-Assessment

信息科技（人工智能）核心素养学业质量评价可视化工具（Web 原型）。

## 文档入口

- [用户使用手册](./docs/用户使用手册.md)

## 技术栈

- React + Vite
- Apache ECharts（`echarts` + `echarts-for-react`）
- SheetJS（`xlsx`）
- Day.js

## 已实现功能（对应 5 个阶段）

1. **基础架构与 UI 布局**
   - 顶部导航：学段切换（小学/初中）、时间跨度选择（半年/一年/五年）
   - 左侧边栏：学生个人看板、班级分析、多班级对比、校际对比、数据管理
   - 中间主体：数据概览卡片 + 雷达图展示区

2. **评价指标与数据模型**
   - 内置小学段与初中段各 8 个指标
   - 数据模型：
     - `Student`: 姓名、学号、班级、学校、学段
     - `Assessment`: 学生ID、学段、8 指标得分、时间戳
   - 自动生成模拟数据：
     - 小学 46 名学生
     - 初中 46 名学生
     - 每人多时间点记录（支持增值轨迹展示）

3. **核心雷达图可视化**
   - 学生增值性图表（多时间点叠加）
   - 班级平均雷达图
   - 多班级对比雷达图（2-3 个班）
   - 校际对比雷达图
   - 全部支持 Tooltip 交互显示分值

4. **数据填写与 Excel 导入**
   - 手动录入：8 指标 1-5 星评分表单
   - Excel 导入：支持列名
     - 必需：`姓名`、`学号`、`评价日期`
     - 指标：`指标1...指标8`（也支持中文指标列名）
   - 导入校验：
     - 分数必须在 1-5 之间
     - 评价日期格式合法
     - 学号需在当前学段学生名单中
   - 导入成功后自动更新图表与统计

5. **长期增值分析**
   - 支持半年/一年/五年跨度
   - 自动比较跨度内“最早记录 vs 最近记录”
   - 显示：
     - 素养提升率
     - 进步最快指标
     - 需进一步提升指标
   - 对 3 分（合格）和 5 分（优秀）提供等级标注

## 运行方式

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```
